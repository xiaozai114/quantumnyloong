# Problem 2.5 完整报告 — LiH 的 LUCJ-SQD vs HF-SQD

**Tencent Sparking Program 2026**

**分子：** LiH，STO-3G，键长 1.55 Å
**活性空间：** 4 条空间轨道，2 个活性电子（Nα = Nβ = 1），冻结 2 个核心电子（Li 1s），JW 映射 → **8 qubits**
**给定参数：** λ = 0.05（CCSD 振幅缩放），S = 1000（采样次数）
**参考值：** RHF = −7.86307516 Ha；FCI（= 该活性空间的 CASCI）= −7.86490425 Ha；相关能 = −1.829 mHa

---

## 摘要

题目要求实现 LUCJ-SQD 流水线并与 HF-SQD 比较，并预判"在 λ = 0.05 下二者可能无可见差异"。本报告完整记录了整个实现与调查过程：从环境搭建、门分解，到 **一个结构性 Jastrow bug**、活性空间口径澄清，再到对"无差异"这一现象**逐层剥离的物理归因**，最后到唯一能真正超越 HF 的**多层双因子分解（DF）LUCJ** 构造。

**核心结论一句话：** 在题目给定的 λ = 0.05、S = 1000 下，LUCJ-SQD 与 HF-SQD **完全相同**（均为 −7.86307516 Ha，距 FCI 1.83 mHa，差异 0 μHa）——这一 null 结果是**真实物理，不是 bug**。只有把 ansatz 升级为多层 DF-LUCJ **并且**放大 λ（λ ≳ 0.3），LUCJ-SQD 才真正超越 HF，逼近甚至命中 FCI。

## 1. 流水线（严格按题目给定的 8 步路线）

| 步骤 | 内容 |
|---|---|
| 1 | 在 TensorCircuit 中实现 **Givens 旋转门**（2-CNOT 分解，2.4 solution 式 21–22）与 **Jastrow 门** `e^{i J_ij n_i n_j} = RZ_i(J/2)·RZ_j(J/2)·RZZ_ij(−J/2)`，其中 `RZZ = CNOT·RZ·CNOT`（式 9–10）。 |
| 2 | 求解 LiH RHF 基态；用 PySCF `get_h1eff/get_h2eff` 约化到 CAS(4,(1,1)) 活性空间哈密顿量（冻结核折进 `ecore`）。 |
| 3 | 构建 **LUCJ** = `U · e^{iJ} · U† |HF⟩`，所有 CCSD 振幅 × λ。`U = exp(κ)` 是轨道旋转，`J` 是对角库仑 Jastrow。 |
| 4 | 对 HF 与 LUCJ 电路各 **采样 1000 次**（从精确 8-qubit 态矢量做多项式抽样，等价于测量 shots）。 |
| 5 | **配置恢复**：对每个自旋块，翻转偏离平均占据数最大的比特，直到恢复 Nα、Nβ（粒子数守恒）。 |
| 6 | 在采样到的行列式子空间构建 CI 矩阵并对角化 → E_SQD。 |
| 7 | PySCF 内置 solver 给出 FCI（= 本活性空间的 CASCI）参考。 |
| 8 | 比较 HF、HF-SQD、LUCJ-SQD、FCI。 |

## 2. 遇到的问题与解决方案（按时间顺序）

### 问题 1 — 环境不兼容（TensorCircuit 0.12 × NumPy 2.x）

**现象：** TensorCircuit 0.12 与 NumPy 2.x 存在 ABI/API 不兼容，导入即崩。

**解决：** 建立专用隔离环境 `/Users/xiezien/.workbuddy/binaries/python/envs/qc`，锁定 `numpy<2` + pyscf + tensorcircuit 0.12 + matplotlib + scipy。此后所有脚本均用该 venv 运行。

---

### 问题 2 — 活性空间口径不明确

**现象：** 初始误从 2.4 solution 推断活性空间，而 2.4 是基于 **H₂** 的推导。用户澄清：2.4 只提供门分解，活性空间定义来自主题目。

**解决：** 采用自洽口径 —— LiH 共 4 个电子，冻结 2 个核心电子（Li 1s）后剩 **2 个活性电子（Nα = Nβ = 1）** 分布在 4 条空间轨道，即 **CAS(4,(1,1))，8 qubits**（已与用户确认）。

---

### 问题 3 —（关键 bug）Jastrow 完全失效

**现象：** 无论 λ 取多大（甚至 λ = 2），LUCJ 与 HF 的保真度恒为 1，LUCJ 恒等于 HF。

**根因：** 原 Jastrow 只做**同自旋相邻对** `n_i·n_j`。但活性空间每个自旋块只有 1 个电子，同自旋占据数乘积 `n_i·n_j ≡ 0`，Jastrow 相位恒为 0 —— 结构上完全失效。

**解决：** 加入**异自旋（αβ）对角库仑** Jastrow 项 `n^a_i · n^b_j`，这是"每自旋 1 电子"下唯一非零的项。修复后 `1 − fidelity ∝ λ⁴`（λ = 0.05 → 8.8×10⁻¹⁰），行为正确。

---

### 问题 4 — 采样在大 λ 下 OOM（exit 137）

**现象：** TensorCircuit 0.12 的 `sample()` 在大 λ 下内存爆炸被杀。

**解决：** 改为**直接从态矢量概率做多项式抽样**（`np.random.choice`），数学上等价于测量 shots，且无内存瓶颈。

## 3. 第一阶段结论：λ = 0.05 下无差异（如实报告）

| 量 | 能量 (Ha) | 距 FCI 误差 |
|---|---|---|
| RHF（全空间） | −7.86307516 | 1.83 mHa |
| **HF-SQD** | **−7.86307516**（M=1） | 1.83 mHa |
| **LUCJ-SQD (λ=0.05)** | **−7.86307516**（M=1） | 1.83 mHa |
| FCI (CASCI) | −7.86490425 | — |

> **|E(LUCJ-SQD) − E(HF-SQD)| = 0.0000 μHa。** 与用户预判完全一致。两次采样都只返回 HF 行列式，故两个 SQD 子空间字面相同（M = 1）。

**这是真实物理，两个独立事实叠加：**

**(a) λ = 0.05 时 LUCJ 与 |HF⟩ 几乎不可区分。**
LUCJ 偏离 HF 是振幅的**二阶**效应（`amplitude ∝ κ·J·λ²`），故 infidelity `1 − |⟨HF|LUCJ⟩|² ∝ λ⁴`：

| λ | 1 − fidelity | 1000 次采样中期望的非 HF shot 数 |
|---|---|---|
| **0.05** | **8.8×10⁻¹⁰** | **~9×10⁻⁷** |
| 0.1 | 1.4×10⁻⁸ | 1.4×10⁻⁵ |
| 0.5 | 8.8×10⁻⁶ | 8.8×10⁻³ |
| 1.0 | 1.4×10⁻⁴ | 0.14 |
| 3.0 | 1.1×10⁻² | 11 |

λ = 0.05 时 1000 次采样几乎永远只见 |HF⟩。`∝ λ⁴` 的干净标度本身就是"Givens+Jastrow 实现正确"的证据。

**(b) 即使 LUCJ 能到达的行列式也对能量无贡献。**
对角 αβ Jastrow 只能到达**单激发**（如 `((0),(1))`）。由 **Brillouin 定理**，单激发不与 HF 参考耦合（`⟨HF|H|单激发⟩ = 0`），加入子空间后 SQD 能量**精确停在 HF**（λ = 3.0、M = 3 时实测 E_SQD = HF，机器精度）。LiH 的相关能几乎全部来自**成对双激发** `((k),(k))`，而这个极简 LUCJ 在任何实际 λ 下都产生不出它们。

**SQD 引擎本身正确**（手动喂入正确行列式验证）：

| 手动构造的子空间 | M | E_SQD (Ha) | 距 FCI 误差 |
|---|---|---|---|
| 仅 HF | 1 | −7.86307516 | 1.83 mHa |
| HF + 一个成对双激发 | 2 | −7.86391595 | 0.99 mHa |
| HF + **全部**成对双激发 | 4 | −7.86485084 | **0.05 mHa** |
| HF + Jastrow 单激发 | 3 | −7.86307516 | 1.83 mHa |

一旦供入携带相关能的双激发，子空间 solver 就能把能量恢复到 **0.05 mHa** —— 证明流水线正确，null 结果确因 (a)(b) 两点。

## 4. 逐个排除"能否让 LUCJ 优于 HF"的假说

用户随后提出多个改进方向，我们逐一验证。**结论是：前三个方向都无法产生差异**，直到第四个（多层）才成功。

### 假说 A — "是不是 Givens 门数上限 g=6 取不到？" → 证伪

Givens 分解本身支持完整 6 个 = C(4,2) 旋转对，**门数不是瓶颈**。真正瓶颈在 κ 的来源：CCSD t1 只有 occ→vir 分量，实际只激活 1 个 Givens (0,1)，vir-vir 块全 0，故生成不出成对双激发。

### 假说 B — "U 用完整参数化（含 vir-vir，从 1-RDM 自然轨道）" → 无差异（反直觉）

改 `lucj_amplitudes(..., full_U=True)`，从 **CCSD 1-RDM 自然轨道旋转** `V=eigh(dm1)`、`κ=logm(V)` 构造完整 κ。结果：自然轨道 κ 只激活 2 个 Givens —— 一个极小的 occ-vir (0,1) θ≈0.036，和一个**大角 vir-vir (2,3) θ≈−1.27**。但 vir-vir 是两个**空轨道**之间的旋转，作用在 HF 上等于恒等（实测保真度 = 1.0）。故 full-U 在全 λ (0.05→3.0) 下 SQD 能量**恒 = HF**，与 sparse 无区别（见 `diagnose_lambda_scan.json`）。

> **精确根因：** 要恢复相关能，κ 必须**大角度把占据轨道旋进虚轨道**。而 LiH 的自然轨道旋转恰好是"vir-vir 大角（对 HF 无作用）+ occ-vir 微小角"，两头都没用。

### 假说 C — "Jastrow 改用 CCSD t2 构造（合题目图注 J from ERIs+t2），在 (0,1) 扫 λ" → 无差异

新增 `jastrow_from_t2()`，从 `t2[0,0,a,a]`（−0.034/−0.028）构造 J。结果：t2 版与 eri 版在整个 (0,1) 内 SQD 能量**恒 = HF**，成对双激发概率 `P(((1,),(1,)))` 在 λ=0.99 仍仅 ~10⁻⁹。

> **决定性根因（本轮闭合，最重要）：** 对角库仑 Jastrow 是**占据数对角**的，**只能给已有支撑的组态加相位，加不出概率为 0 的组态**。而单层 `U e^{iJ} U†` + 每自旋独立轨道旋转下，`U†|HF⟩` 里成对双激发 `((1,),(1,))` 的支撑精确 ≈ 0（单个 occ-vir Givens 只搬单自旋 → 只产生单激发；α、β 无法协同同跳）。所以**无论 J 用 eri 还是 t2，都注入不了成对双激发**。
>
> **验证：** 手动把 κ[0,1] 设为大角 θ 扫描 → `U†|HF⟩` 的成对双激发支撑随 θ 上升（θ=1.0 → 0.50），此时 LUCJ 才采到成对双激发、E_SQD 才下降。证明**唯一能注入成对双激发的是大角 occ-vir 旋转**，与 Jastrow 来源无关。

## 5. 最终方案：多层双因子分解（DF）LUCJ

### 理论依据

标准 UCJ 的双因子分解形式为

$$|\Psi_{\text{LUCJ}}\rangle = \Big(\prod_{k=1}^{L} U_k\, e^{i\hat J_k}\, U_k^\dagger\Big)\,|\text{HF}\rangle$$

对 LiH 单占据（nocc=1），成对双通道 `T_{ab} = t2[0,0,a,b]`（3×3 对称阵）特征分解 `T = Σ_k g_k v_k v_k^T`，得到 **L = 3 层**，`g = [−0.0343, −0.0343, −0.0163]`。每层 `U_k` 把占据轨道旋进虚方向 `v_k`（**含大角 occ-vir 分量**，来自 t2 而非 t1）。多层 `U_k e^{iJ_k} U_k†` 串联，正是把成对双激发注入参考态的机制 —— 这是单层 + 对角 Jastrow 结构上做不到的。

### 代码实现（`problem_2_5_lucj_sqd.py`）

- `ccsd_active()`：`frozen = core + 顶部虚轨道`，使 CCSD 的 occ/vir 维度精确等于 8-qubit 活性空间（nocc=1, nvir=3），t2 才能干净映射到 4 条空间轨道。
- `double_factorization_layers()`：返回 `[(g_k, kappa_k)]`，`kappa_k` 是把 occ0 旋进 v_k 的单位反对称元。
- `lucj_circuit_multilayer(..., theta_fixed=π/4)`：实现 `∏_k U_k e^{iJ_k} U_k†|HF⟩`；`main()` 已切到多层。
- 新增诊断脚本 `diagnose_multilayer.py`（200k 采样扫 λ）+ `multilayer_scan.png/json`。

### 关键缩放修正（本方案成败所在）

成对双激发幅度 `A ~ sin²θ·(1 − e^{iφ}) ~ θ²·φ`，**线性于 Jastrow 相位 φ**。

- **错误做法（第一版）：** `θ = √(|g|·λ)`，导致 `A ~ g²·λ` 被平方压死 —— λ=1 时 p_paired 仍 ~10⁻⁶，采不到（实测失败）。
- **正确做法：** θ 固定为 O(1)（π/4，sin²=1/2），把 t2·λ 全部放进相位 `φ_k = g_k·λ`。这样 `p_paired ∝ g_k·λ` 线性上升。

### 决定性结果（终于产生差异！200k 采样，λ 扫描）

| λ | p(paired) | 采到双激发? | M | E(LUCJ-SQD) (Ha) | 距 FCI 误差 |
|---|---|---|---|---|---|
| **0.05** | 4.1×10⁻⁷ | 否 | 1 | −7.86307516 | **1.83 mHa（= HF-SQD）** |
| 0.3 | 1.5×10⁻⁵ | 是 | 6 | −7.86485084 | 0.053 mHa |
| 0.5 | 4.1×10⁻⁵ | 是 | 8 | −7.86485084 | 0.053 mHa |
| **0.7** | 8.0×10⁻⁵ | 是 | 10 | **−7.86490425** | **0.000 mHa（= FCI）** |
| **1.0** | 1.6×10⁻⁴ | 是 | 10 | **−7.86490425** | **0.000 mHa（= FCI）** |

- **变分下界**（HF + 全部成对双激发，M=4）= −7.86485084（**0.053 mHa**）——这是对角 Jastrow-LUCJ 能达到的极限（只能注入成对双激发）。
- **λ = 0.05：** p_paired = 4×10⁻⁷ < 采样阈值 → LUCJ-SQD ≡ HF-SQD（**验证预判 a**）。
- **λ ≥ 0.3：** 稳定采到全部成对双激发 → 锁到变分下界 0.053 mHa；λ = 0.7/1.0 时子空间 M=10 已覆盖 FCI 所需组态 → **命中 FCI 0.000 mHa（验证预判 b）**。
- λ = 0.1/0.2 处因 p~10⁻⁶ 边界有采样涨落（非物理问题，纯统计）。

汇总图 `multilayer_scan.png`：左图 paired 权重随 λ **线性上升**；右图误差从 HF 水平掉到变分下界/FCI。

## 6. 总结论

1. **题目原设定（λ=0.05, S=1000）下 LUCJ-SQD = HF-SQD**，差异 0 μHa，均距 FCI 1.83 mHa —— **如实报告，与用户预判一致**。这是三重物理必然：
   - (a) 偏离 ∝ λ⁴（此处 ~10⁻⁹），1000 次采样只见 |HF⟩；
   - (b) 对角 Jastrow 结构上产生不出成对双激发（需大角 occ-vir 的 U）；
   - (c) 单激发按 Brillouin 定理对能量无贡献。

2. **单层任何变体都无法超越 HF**：完整参数化 U（含 vir-vir 自然轨道旋转）、t2 驱动的 Jastrow，逐一验证均无差异 —— 因为它们要么作用在空轨道上恒等，要么只能给已有支撑加相位。

3. **多层 DF-LUCJ 是题目框架内唯一真正超越 HF 的构造**：多层 `U_k`（含大角 occ-vir）串联把成对双激发注入 HF。但在 λ=0.05 下 paired 权重仍低于采样阈值，故默认设定的 null 结论不变；只有放大 λ（≳ 0.3）才显现优势，λ ≥ 0.7 时甚至命中 FCI。
