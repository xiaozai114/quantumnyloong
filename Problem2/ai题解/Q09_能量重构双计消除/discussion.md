# Q09：能量重构——双计问题的代数消除

## 题目

分子 (c) H₂O，碎片划分为 O 和 H₂ 两部分。

给定数值（单位 Ha）：

| 量 | 数值 |
|---|---|
| $E_{\text{MF}}$（全分子平均场能量） | $-74.963$ |
| $E_O$（O 碎片高阶 solver 能量） | $-75.010$ |
| $E_{\text{MF},O}$（O 碎片 HF solver 能量） | $-74.980$ |
| $E_{H_2}$（H₂ 碎片高阶 solver 能量） | $-75.005$ |
| $E_{\text{MF},H_2}$（H₂ 碎片 HF solver 能量） | $-74.983$ |

要求：

1. 把 $E_f = E_{\text{core},f} + E_{\text{elec},f}$ 与 $E_{\text{MF},f} = E_{\text{core},f} + E_{\text{HF-elec},f}$ 代入 $(E_f - E_{\text{MF},f})$，证明 $E_{\text{core},f}$ 抵消，只剩 $\Delta E_{\text{corr},f} = E_{\text{elec},f} - E_{\text{HF-elec},f}$。
2. 解释 $\Delta E_{\text{corr},f}$ 为何局域、为何无双计。
3. 验证：所有碎片都用 HF 求解器时 $E_{\text{total}} = E_{\text{MF}}$。
4. 计算重构后的总能量。
5. 进阶：分块累积量重构——基本思想？何时更精确？

## 我的想法

DMET 把大分子切成若干碎片，对每个碎片在"碎片轨道 + 浴轨道"构成的嵌入空间里分别跑高阶 solver，再拼回总能量。最朴素的做法是直接把各碎片能量相加：$\sum_f E_f$。但浴轨道是按碎片分别构造的，相邻碎片的浴会有重叠，重叠区域的那部分能量会被算两次，导致 $\sum_f E_f$ 系统性偏大——这就是"双计"（double counting）。

题目给的标准重构公式是

$$E_{\text{total}} = E_{\text{MF}} + \sum_f \big(E_f - E_{\text{MF},f}\big)$$

也就是在平均场总能量 $E_{\text{MF}}$ 之上，逐片段加上"高阶 solver 与 HF solver 在同一嵌入空间里的能量差"。直觉上：$E_{\text{MF}}$ 已经把整个分子的 HF 能量算对了；每个碎片的差值只补充"该碎片局部多出来的关联修正"，而把浴重叠部分的 HF 贡献在 $E_f$ 和 $E_{\text{MF},f}$ 中各算一次又各减一次，恰好抵消。

要害在于：$E_f$ 和 $E_{\text{MF},f}$ 用的是**同一个嵌入 Hamiltonian**、同一个核吸引、同一份浴轨道，区别只在电子部分的求解器。所以做差时，所有与 solver 无关的项（核排斥、碎片内核吸引、HF 平均场下的浴贡献）都被精确扣除，剩下的纯粹是"该碎片嵌入空间内的电子关联修正"。

至于核能 $E_{NN}$：它在 DMET 碎片化过程中根本不参与分解，只作为整体出现在 $E_{\text{MF}}$ 中一次；$E_f$、$E_{\text{MF},f}$ 都是嵌入空间里的电子能量，差值里不含核能，所以核能天然无双计。

## 讨论

### 1. $E_{\text{core},f}$ 抵消的代数推导

把片段能量按是否依赖 solver 拆开：

$$E_f = E_{\text{core},f} + E_{\text{elec},f}$$

$$E_{\text{MF},f} = E_{\text{core},f} + E_{\text{HF-elec},f}$$

其中 $E_{\text{core},f}$ 是 solver 无关的部分（嵌入空间里的核–核、核–电子吸引等"骨架"贡献），$E_{\text{elec},f}$ 是高阶 solver 给出的电子部分，$E_{\text{HF-elec},f}$ 是 HF solver 给出的电子部分。代入做差：

$$
\begin{aligned}
E_f - E_{\text{MF},f}
&= \big(E_{\text{core},f} + E_{\text{elec},f}\big) - \big(E_{\text{core},f} + E_{\text{HF-elec},f}\big) \\
&= \big(E_{\text{core},f} - E_{\text{core},f}\big) + \big(E_{\text{elec},f} - E_{\text{HF-elec},f}\big) \\
&= E_{\text{elec},f} - E_{\text{HF-elec},f}
\end{aligned}
$$

$E_{\text{core},f}$ 一加一减完全抵消，剩下的纯粹是电子关联修正：

$$\boxed{\;\Delta E_{\text{corr},f} \;=\; E_f - E_{\text{MF},f} \;=\; E_{\text{elec},f} - E_{\text{HF-elec},f}\;}$$

这步推导的关键前提是：$E_f$ 和 $E_{\text{MF},f}$ 在**同一个嵌入空间**、**同一个 core 项**下计算，区别仅在电子部分的求解器。若两者用了不同的浴或不同的核处理，$E_{\text{core},f}$ 就不会干净抵消，标准重构公式也不再成立。

### 2. 为什么 $\Delta E_{\text{corr},f}$ 局域且无双计

**局域性。** $\Delta E_{\text{corr},f}$ 只涉及碎片 $f$ 的嵌入空间（碎片轨道 + 浴轨道）内的电子关联。电子关联本质上是局域的——电子主要和近邻电子发生库仑纠缠。跨碎片的长程关联（色散、远距电荷转移）在标准 DMET 中是被丢弃的，但这是**系统性遗漏**，属于 $\varepsilon_{\text{cross}}$ 误差源，而不是双计——双计是"多算"，遗漏是"少算"，两者方向相反，不能混为一谈。

**无双计的根源：浴重叠的 HF 贡献被精确扣除。** 朴素求和 $\sum_f E_f$ 之所以偏大，是因为相邻碎片共享的浴轨道在 $E_f$ 和 $E_{f'}$ 里各算了一次。标准重构通过减去 $E_{\text{MF},f}$ 把这件事处理干净：

- $\sum_f E_{\text{MF},f}$ 包含了重叠浴部分的**平均场版本**贡献（被算了两次）；
- $\sum_f E_f$ 包含了重叠浴部分的**高阶 solver 版本**贡献（也被算了两次）；
- 取差 $\sum_f (E_f - E_{\text{MF},f})$ 时，重叠部分的"被算两次"在差值里**同样出现两次**：一次是 $E_f$ 里的高阶版本，一次是 $-E_{\text{MF},f}$ 里的 HF 版本。两者做差，重叠浴的 HF 贡献被高阶 solver 的对应贡献"替换"为关联修正，而不会被额外再加一遍。

换句话说，"双计"在 $E_f$ 和 $E_{\text{MF},f}$ 中是**同构的**——同一个浴重叠、同一份 HF 平均场，被加的次数也一样。同构的双计在做差时自然消去，剩下的只是"高阶 solver 比 HF 多算出来的那份局域关联"。

**核能只出现一次。** 核排斥 $E_{NN}$ 在 DMET 碎片化过程中是固定背景，$E_f$、$E_{\text{MF},f}$ 都只是嵌入空间的电子能量，差值 $\Delta E_{\text{corr},f}$ 不含任何核能项。$E_{NN}$ 只通过 $E_{\text{MF}}$（全分子平均场能量 = 电子 HF 能量 + 核排斥）进入总能量公式一次。因此核能这一项天然无双计——它压根没参与碎片分解。

把以上几点合起来：标准重构公式里，被加和的 $\Delta E_{\text{corr},f}$ 既不含核能，也不含浴重叠的 HF 重复，只剩纯电子的局域关联修正，因此无双计。

### 3. 全 HF 验证：$E_{\text{total}} = E_{\text{MF}}$

若每个碎片都用 HF 求解器，那么在同一嵌入空间里 $E_f$ 和 $E_{\text{MF},f}$ 是同一个量：

$$E_f = E_{\text{MF},f} \;\Longrightarrow\; \Delta E_{\text{corr},f} = E_f - E_{\text{MF},f} = 0 \quad \forall f$$

代入重构公式：

$$E_{\text{total}} = E_{\text{MF}} + \sum_f 0 = E_{\text{MF}} \quad \checkmark$$

这正是一个自洽性检验：DMET 的能量重构公式在"没有关联"的极限下必须回到全分子的 HF 能量。这个性质看似平凡，但它强约束了重构公式的形式——任何不满足"$\Delta E_{\text{corr},f}$ 在 HF 极限为零"的重构方案都是有问题的。代数上看，这正是因为 $E_{\text{core},f}$ 抵消、浴重叠 HF 抵消，剩余项在 HF 极限下自然归零。

### 4. 数值计算重构总能量

对 O 碎片：

$$\Delta E_{\text{corr},O} = E_O - E_{\text{MF},O} = (-75.010) - (-74.980) = -0.030 \text{ Ha}$$

对 H₂ 碎片：

$$\Delta E_{\text{corr},H_2} = E_{H_2} - E_{\text{MF},H_2} = (-75.005) - (-74.983) = -0.022 \text{ Ha}$$

两者均为负，符合"高阶 solver 比 HF 能量更低"的预期（关联能总是降低总能量）。代入重构公式：

$$
\begin{aligned}
E_{\text{total}} &= E_{\text{MF}} + \Delta E_{\text{corr},O} + \Delta E_{\text{corr},H_2} \\
&= (-74.963) + (-0.030) + (-0.022) \\
&= -74.963 - 0.052 \\
&= \boxed{-75.015 \text{ Ha}}
\end{aligned}
$$

重构总能量比 MF 低 $0.052$ Ha（约 $1.4$ eV 或 $32.6$ kcal/mol），这是 DMET 捕获到的电子关联修正的量级。注意这个值**不等于**完整 CCSD(T) 的关联能——DMET 会丢失跨碎片关联，所以 $-75.015$ Ha 是一个"局域关联已被加上、跨碎片关联被丢弃"的近似值。

### 5. 进阶：分块累积量重构

**标准重构的局限。** 公式 $E_{\text{total}} = E_{\text{MF}} + \sum_f \Delta E_{\text{corr},f}$ 把每个碎片的关联能当作一个整体标量相加。这隐含假设：关联能可以按碎片简单加和。但电子关联在数学上是一个多体对象——两电子间的关联（2-body）、三电子间的关联（3-body）等有不同的空间结构。把所有阶混在一起相加，跨碎片的那部分 2-body 关联（如远距色散）就被整体丢弃了，无法在重构阶段补救。

**累积量分解的基本思想。** 把总能量按连接阶数（cumulant order）展开：

$$E = E^{(1)} + E^{(2)} + E^{(3)} + \cdots$$

- $E^{(1)}$：1-body 累积量，对应单粒子密度矩阵贡献，近似等于 HF 部分（单电子动能 + 平均场排斥）；
- $E^{(2)}$：2-body 累积量，对应电子对关联，是关联能的主要部分（MP2、CCSD 主体）；
- $E^{(3)}$ 及更高：三体及以上关联，通常量级较小可忽略，但在强相关体系下不可省。

对**每一阶分别做 DMET 重构**，而不是对总能量做一次重构：

$$E_{\text{total}} = E_{\text{MF}} + \sum_f \Big[\big(E^{(2)}_f - E^{(2)}_{\text{MF},f}\big) + \big(E^{(3)}_f - E^{(3)}_{\text{MF},f}\big) + \cdots\Big]$$

这里 $E^{(n)}_f$ 是碎片 $f$ 嵌入空间里第 $n$ 阶累积量贡献的能量，$E^{(n)}_{\text{MF},f}$ 是对应的 HF 参考值（HF 只有 1-body，所以 $E^{(n\geq 2)}_{\text{MF},f}=0$，做差就是 $E^{(n)}_f$ 本身）。

**为什么分阶重构能改善跨碎片关联？** 关键在于：2-body 累积量虽然定义在碎片嵌入空间内，但浴轨道已经携带了环境信息。当相邻碎片的浴有重叠时，重叠区域里的 2-body 关联（一对电子分别"伸出"到两个碎片的浴里）可以被**两个碎片各自部分地捕获**，分阶重构允许我们把这部分的连接结构显式保留，而不是在标量加和里被压平。1-body 部分仍然由 $E_{\text{MF}}$ 一次性兜底，避免 HF 层的双计；高阶部分才进入碎片加和。

**何时明显更精确？**

- **跨碎片 2-body 关联显著时**：色散力主导的体系（稀有气体簇、范德华复合物）、$\pi$ 共轭体系（多环芳烃、DNA 碱基堆叠）。标准重构丢失跨碎片色散，但 2-body 累积量可通过浴轨道重叠部分部分捕获。
- **强关联体系**：例如 N₂ 拉伸到 $2.0$ Å 附近解离，静态关联占主导，2-body 累积量的非局域贡献变大，3-body 也开始不可忽略。此时分阶重构能更好地分离"哪些关联是局域的、哪些必须跨碎片处理"。
- **大基组**：虚拟轨道丰富，跨碎片虚拟–虚拟关联（动态关联的主体）更多，标准重构把它们整体丢弃的损失更大；累积量分解能更好地区分局域和非局域贡献。

**代价。** 标准重构只需要每个碎片的总能量（一个标量），而分块累积量重构需要每个碎片的 2-RDM 的**连接部分**（即 2-body 累积量），甚至更高阶的连接 RDM。这意味着 solver 必须能输出这些量（FCI、DMRG、selected CI 可以；CCSD 需额外推导），且存储和通信开销显著增大（2-RDM 对 $N_{\text{emb}}$ 的标度是 $O(N_{\text{emb}}^4)$）。因此分块累积量重构通常只在需要高精度跨碎片关联的中等大小体系上才划算。

## 结论

1. **$E_{\text{core},f}$ 抵消**：在同一嵌入空间、同一核骨架下，$E_f - E_{\text{MF},f}$ 把 solver 无关的 $E_{\text{core},f}$ 一加一减消去，只剩纯电子关联修正 $\Delta E_{\text{corr},f} = E_{\text{elec},f} - E_{\text{HF-elec},f}$。

2. **无双计的根源**：浴重叠的 HF 贡献在 $E_f$ 与 $E_{\text{MF},f}$ 中**同构地**出现两次，做差时同步抵消，只替换为对应的关联修正；核能 $E_{NN}$ 不参与碎片分解，只通过 $E_{\text{MF}}$ 进入一次。两者合起来保证 $\sum_f \Delta E_{\text{corr},f}$ 既无双计也无核能重复。跨碎片关联被丢失是**遗漏**而非双计，方向相反。

3. **全 HF 验证**：所有碎片用 HF 时 $E_f = E_{\text{MF},f}$，$\Delta E_{\text{corr},f}=0$，$E_{\text{total}} = E_{\text{MF}}$。这是重构公式必须满足的自洽下限。

4. **数值结果**：$\Delta E_{\text{corr},O} = -0.030$ Ha，$\Delta E_{\text{corr},H_2} = -0.022$ Ha，重构总能量 $E_{\text{total}} = -74.963 - 0.030 - 0.022 = \boxed{-75.015 \text{ Ha}}$。

5. **分块累积量重构**：把能量按 1-body / 2-body / 3-body… 累积量分阶，对每阶分别做 DMET 重构。1-body 由 $E_{\text{MF}}$ 兜底，高阶按碎片加和。在跨碎片 2-body 关联显著（色散、$\pi$ 共轭）、强相关拉伸体系（N₂ 解离）、大基组动态关联丰富的场景下明显更精确；代价是需要 2-RDM 连接部分乃至更高阶 RDM，计算和存储开销远大于标量能量重构。

```python
# Q09 数值重构验证
E_MF       = -74.963
E_O        = -75.010

assert E_MF + 0 + 0 == E_MF       # 通过

```
